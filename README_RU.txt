CHESS COACH — Android-проект с загрузкой ресурсов при первом запуске

КАК РАБОТАЕТ ОФЛАЙН
1. Установи APK и запусти приложение при подключённом интернете.
2. Приложение скачает chess.js и файлы Stockfish в приватную папку приложения. На экране будет показан прогресс.
3. После сообщения «Готово» доска, импорт PGN, навигация по ходам и движок Stockfish работают без интернета.
4. Скачанные файлы остаются на телефоне между запусками. Очистка данных приложения или его удаление удалит эти файлы — тогда для повторной загрузки нужен интернет.

ПЕРВЫЙ ЗАПУСК
Нужен интернет и несколько мегабайт свободного места. Если загрузка не удалась, проверь подключение и нажми «Повторить загрузку». Приложение не должно требовать интернет для последующих запусков после успешной загрузки ресурсов.

СБОРКА APK ЧЕРЕЗ GITHUB ACTIONS
1. Создай новый репозиторий на GitHub и загрузи в него содержимое этой папки.
2. Открой Actions и запусти workflow «Build Chess Coach APK» (или сделай push в main).
3. В завершившемся запуске скачай artifact `chess-coach-debug-apk`.
4. Внутри находится `app-debug.apk`. Скачай его на Android и установи.

ЧТО РАБОТАЕТ
- Импорт PGN текстом или файлом.
- Навигация по ходам и интерактивная доска.
- Анализ выбранной позиции и последовательный анализ партии Stockfish.
- После первоначальной загрузки ресурсов анализ выполняется локально на устройстве.

ОГРАНИЧЕНИЯ
- Нет облачного ИИ и онлайн-синхронизации; текущий анализ работает локально.
- При первом запуске требуется интернет для загрузки chess.js и Stockfish.
- Для обновления движка в будущем потребуется отдельная логика обновления или новая версия приложения.

Package: com.nail.chesscoach
Минимальная версия Android: 6.0 (API 23)
